Store Name: BlockUSM - Stop Doomscrolling

Short Description: A free extension to block yourself from accessing websites, remove distracting elements from social media like feeds and shorts, and remove sites from search results.

Page: BlockUSM is a comprehensive social media blocker - you can block websites entirely, block only certain features of a site, and remove websites from search results on search engines such as Google.

For example:
- Block a website such as TikTok entirely - trying to access it will take you to a page notifying you that the site is forbidden
- Remove distracting features such as YouTube recommended videos or Instagram reels. Options already exist for the popular social media sites, but you can configure the extension to remove any element from any website.
- Hide websites such as Reddit from search engine results. Searching for anything will no longer show results from Reddit.

Currently Supported search engines are:
- Google
- DuckDuckGo

BlockUSM is **completely free** with no ads and always will be.

BlockUSM is designed to remove temptations and stop the habit of opening social media sites. If you are addicted to social media, consider reading my free guide [QuitUSM](https://mohamedlashuel.github.io/QuitUSM) to understand and overcome social media addiction.
